# SOROBAN

SHIRUBE(現場×ポスト×シフト管理)と連携する経理アプリ。
SHIRUBE本体には経理機能を入れず、CSVの出し入れで連携する。
データはブラウザの中だけで処理し、外部のサーバーには送らない。

## ロードマップ

1. 請求書(フェーズ1・実装中)
2. 勤務表
3. 外注費チェック
4. 経費管理

設計方針は [docs/design.md](docs/design.md) を参照。

## 使い方(請求書)

1. **実績の取り込み**:SHIRUBEの実績明細CSV・機材明細CSVを選ぶ(複数可、UTF-8 / Shift_JIS)
2. **マスタ**:自社情報・元請け・現場・人の単価・機材の単価を入力する
   - 「まとめて追加」で、取り込んだデータにあって未登録の行を作れる
   - 変更したら「マスタを書き出す」でJSONを共有フォルダに保存する(これが正本)
3. **請求書**:請求月を選ぶと、元請けごとの締め日で集計された請求書(表紙 + 現場ごとの内訳書)ができる
   - 経費(交通費・駐車場代など)と備考は請求書ごとに手入力する
   - 印刷 → 「PDFに保存」でPDFにする(表紙はA4横、内訳書はA4縦)
   - 「請求明細CSV」「内訳明細CSV」で明細をCSVに保存する

`sample/` に架空のサンプルデータがある(`実績明細_202610.csv`・`機材明細_202610.csv`・`soroban-masters_sample.json`)。
請求月を 2026年10月 にすると請求書が出る。

## 開発

```sh
npm install
npm run dev        # 開発サーバー
npm test           # 単体テスト(集計・端数処理・税計算)
npm run build      # 型チェック + ビルド(dist/ に静的ファイル)
```

ビルド結果は静的ファイルだけなので、Cloudflare Pages(無料)に置くか、`npm run preview` で手元で開いて使う。
