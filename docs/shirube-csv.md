# SHIRUBE → SOROBAN CSV出力仕様

SHIRUBEに実装するCSVエクスポートの仕様。SOROBANはこの形式を読み込んで請求書(表紙 + 現場ごとの内訳書)を作る。

## 考え方(ここだけ押さえれば処理しやすい)

| SOROBANでの役割 | SHIRUBEで出す項目 | ルール |
|---|---|---|
| 表紙の1行 / 内訳書の1枚 | **現場ID** | 元請けとの契約(業務)の単位にする。例:「○○管内維持修繕業務」。日々の作業ごとに現場を分けない |
| 内訳書の「工事名」欄 | **工事名** | その日の伝票(作業確認書)に書く作業名。例:「舗装小補修」「植栽関係作業②」。なければ空でよい(SOROBANが現場名で埋める) |
| 内訳書の1行 | 勤務日 + 工事名 + 開始 + 終了 | この4つが同じ隊員は1行にまとめ、延べ時間を足す。行を分けたいときは工事名を変える |
| 昼単価 / 夜単価 | **勤務区分**(日勤 / 夜勤) | **受注の区分**を入れる。「夜間1名」の受注なら17:00開始でも「夜勤」。昼夜を時刻で分けるか勤務区分で決めるかは、SOROBANの元請け・現場ごとの設定で切り替える |
| 内訳書を分ける / 単価を分ける | **職種**(規制保安員 / 作業員 など) | 同じ現場でも単価や内訳書を分けたいものは職種を変える。分けないなら全員同じ値(空でも可) |
| 請求の対象期間 | 勤務日 | 夜勤で日をまたいでも、**勤務開始日**を入れる |

## ファイル

| ファイル | 内容 | 必須 |
|---|---|---|
| `実績明細_YYYYMM.csv` | 1行 = 隊員 × 日 × 現場 × ポスト | ◎ |
| `機材明細_YYYYMM.csv` | 1行 = 日 × 現場 × 工事名 × 品目 | 任意(SOROBANで手入力もできる) |

共通の形式:

- 文字コードは **UTF-8(BOM付き)**、改行は CRLF(Excelで開いても文字化けしない)
- 1行目はヘッダー(下表の列名のとおり、日本語)。列の順番は自由、余分な列があっても無視される
- 日付は `YYYY-MM-DD`、時刻は `HH:MM`(24時間表記)、分・数量は整数
- カンマ・改行・ダブルクォートを含む値はダブルクォートで囲む(RFC 4180)
- 締め日をまたぐ元請け(20日締めなど)があるので、**月の範囲は前月21日〜当月末のように広めに出してよい**(SOROBANが締め日で切り出す)

## 実績明細CSV

| 列名 | 必須 | 例 | 説明 |
|---|---|---|---|
| 実績ID | ◎ | R20261001-0012 | 一意で、**出し直しても変わらない**ID。SOROBANは同じIDを二重に取り込まない |
| 勤務日 | ◎ | 2026-10-01 | 勤務開始日 |
| 元請けID | ◎ | C001 | SOROBANのマスタと突き合わせるキー。変えない |
| 元請け名 | | 東西道路管理株式会社 | 表示用 |
| 現場ID | ◎ | S01 | 上の「考え方」参照。元請けの中で一意 |
| 現場名 | | 中央道 みどり管内維持修繕業務 | 表示用。工事名が空のときの代わり |
| ポストID / ポスト名 | | P1 / 規制帯 | 今は使わない(将来の勤務表用) |
| 隊員ID / 隊員名 | | E001 / 山田 | 警告の表示用(将来の勤務表・外注費チェック用) |
| 職種 | | 規制保安員 | 上の「考え方」参照 |
| 工事名 | | 舗装小補修 | 上の「考え方」参照。列名は「作業内容」でも読める |
| 勤務区分 | ◎ | 日勤 / 夜勤 | 受注の区分。「夜」を含む値を夜勤として扱う |
| 開始 | ◎ | 19:00 | |
| 終了 | ◎ | 04:00 | 開始以前の時刻なら翌日 |
| 休憩分 | ◎ | 60 | |
| 実働分 | ◎ | 480 | 残業を含む総実働。**請求の時間はこの値が正**(開始・終了・休憩と合わないと警告) |
| 残業分 | | 0 | 実働分のうち残業。人工で請求する元請けだけ使う |
| 伝票番号 | | D-1234 | 作業確認書の番号。空だと警告 |
| 状態 | ◎ | 確定 / 未確定 | 未確定だと警告(請求書には載る) |

例:

```csv

R20261002-0007,2026-10-02,C001,東西道路管理株式会社,S01,中央道 みどり管内維持修繕業務,P1,規制帯,E003,鈴木,規制保安員,構造物補修,夜勤,19:00,04:00,60,480,0,D-2003,確定
```

## 機材明細CSV

| 列名 | 必須 | 例 | 説明 |
|---|---|---|---|
| 機材明細ID | ◎ | M20261001-001 | 一意で、出し直しても変わらないID |
| 勤務日 | ◎ | 2026-10-01 | |
| 元請けID | ◎ | C001 | |
| 現場ID | ◎ | S02 | |
| 工事名 | | さくらバイパス除草工 | 実績と同じ工事名なら、内訳書の同じ行に載る。空ならその日の最初の行 |
| 品目 | ◎ | 車両トラック | SOROBANの機材単価マスタの品目名と一致させる |
| 数量 | ◎ | 2 | 台数(1式なら1) |
| 伝票番号 | | D-2004 | |

## 運用メモ

- 実績を直してCSVを出し直したときは、SOROBANの「取り込んだデータを消す」→ 取り込み直し(IDが同じ行は二重に取り込まないため)
- 元請けID・現場IDを変えると、SOROBANのマスタ(単価・表紙の現場名)と結びつかなくなる。変える場合はSOROBAN側も合わせる

## SHIRUBE側の実装状況(2026-10-01、SHIRUBE ver 0.19.0)

`cocham139/shift-map-app` の `feature/soroban-csv-export` ブランチで、実績明細CSVの出力を実装した(管理設定 →「経理(SOROBAN)用CSV出力」)。

| 項目 | SHIRUBEでの出し方 |
|---|---|
| 実績ID | `シフトのID:隊員のID`(名簿にない手打ちの隊員は名前)。出し直しても変わらない |
| 元請けID / 元請け名 | どちらも**元請け名そのまま**。表記を変えるとSOROBANのマスタと結びつかなくなるので、SHIRUBEの管理設定のドロップリストから選ぶ運用にする |
| 現場ID | SHIRUBEの現場のID(UUID) |
| 職種・工事名・伝票番号 | シフトの入力欄(任意)。職種は管理設定でよく使うものを登録できる |
| 休憩分 | シフトの「休憩(分)」。初期値60 |
| 実働分 | 終了 − 開始 − 休憩(終了が開始以前なら翌日)。隊員ごとの実績入力はまだない |
| 残業分 | 常に0(入力欄がない) |
| 状態 | 伝票番号が入っている、または伝票の写真(「伝票なし」の確認)がある日は「確定」。それ以外は「未確定」 |
| 出力範囲 | 選んだ月の前月21日〜当月末 |

出力されないもの: 終了時刻が未入力のシフト、隊員が入っていないシフト(出力画面に件数を表示)。
