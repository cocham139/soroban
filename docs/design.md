# SOROBAN 設計方針(フェーズ1:請求書)

## 役割

- SHIRUBE:現場の「事実」(誰が・いつ・どの現場/ポストで・何時間働いたか、伝票番号)を持つ
- SOROBAN:「お金」(単価・締め日・請求単位・端数処理・税)を持ち、整った数字を請求書の形に出す
- 連携はCSV。API連携はしない
- 決算機能は持たない。将来は弥生・freee向けの仕訳CSVを出力するアダプタを追加する

## 構成

- クライアント完結(サーバー・DBなし)。データはブラウザ内で処理し、外部に送らない
- Vite + React + TypeScript(SHIRUBEに揃える)
- CSV読み込み:自前の小さなパーサー(RFC 4180)。文字コードはブラウザ標準の TextDecoder で UTF-8 / Shift_JIS を判別
- 印刷:CSS `@media print` でA4レイアウト → ブラウザの印刷 / PDF保存
- テスト:Vitest(集計・端数処理・税計算は必ずテストを書く)
- 金額は整数の円で扱い、浮動小数点を使わない
- ホスティング:非公開リポジトリのため Cloudflare Pages(無料)またはローカル実行
  (GitHub Pages は非公開リポジトリでは有料プラン)

### 永続化

- マスタ(自社情報・元請け・単価表)は画面で入力し、JSONファイルで書き出し / 読み込み
- 前回の内容はブラウザ(localStorage)にも保持するが、正本はJSONファイル
- 発行した請求書は「請求明細CSV + PDF」を共有フォルダに保存し、それを履歴とする
- 請求書番号はDBの連番に頼らず `YYYYMM-元請けID-枝番` のように決定的に生成する
- 複数人で同時にマスタを編集する必要が出たら、Supabase等の導入を再検討する

## 入力:SHIRUBEのCSV(2種類)

取り込み画面でまとめて選べる。ヘッダーで種類を判別する。

ファイル名:`実績明細_YYYYMM.csv`
1行 = 隊員 × 日 × 現場 × ポスト(縦持ち)。◎は必須の列、ほかは任意(なくても読める)。

| ◎実績ID | R-20261001-0012 | 一意。二重取り込みの検知に使う |
| ◎勤務日 | 2026-10-01 | YYYY-MM-DD |
| ◎元請けID | C003 | 突き合わせはIDで行う |
| 元請け名 | ○○建設 | 表示用 |
| ◎現場ID | S015 | |
| 現場名 | △△ビル新築 | 表示用 |
| ポストID / ポスト名 | P2 / 正門 | |
| 隊員ID / 隊員名 | E042 / 山田 | |
| 職種 | 規制保安員 / 作業員 | 単価と内訳書を分ける単位 |
| 作業内容 | 舗装小補修 | 内訳書の「工事名」欄。同じ日・作業内容・時間の隊員は1行にまとめる |
| ◎勤務区分 | 日勤 / 夜勤 | 人工の元請けで日勤・夜勤の単価を選ぶ |

| ◎状態 | 確定 / 未確定 | |

ファイル名:`機材明細_YYYYMM.csv`
1行 = 日 × 現場 × 作業 × 品目(車両トラック・パッカー車・規制材一式など)

| 列 | 例 | 備考 |
|---|---|---|
| ◎機材明細ID | M-20261001-001 | 一意 |
| ◎勤務日 | 2026-10-01 | |
| ◎元請けID / ◎現場ID | C001 / S02 | |
| 作業内容 | ○○除草工 | 実績と同じ日・作業内容の行に載せる |
| ◎品目 | 車両トラック | 単価表の品目と一致させる |
| ◎数量 | 2 | 整数(台・式) |
| 伝票番号 | D-1234 | |

### 形式のルール

- SHIRUBEからの出力は UTF-8(BOM付き)
- SOROBANは Shift_JIS も読み込める(Excelで手直しして保存された場合に備える)
- ヘッダーは日本語で固定。列の順番は問わない

## SOROBAN側のマスタ(画面で入力)

### 自社情報

社名、住所、TEL、FAX、適格請求書の登録番号、振込先、消費税の端数処理

### 元請け

| 項目 | 内容 |
|---|---|
| 元請けID | SHIRUBEのIDと一致させる |
| 正式名称 / 敬称 | 御中 など |
| 計算方式 | 時間単価 / 人工 |
| 夜勤帯 | 時間単価のとき、夜勤単価にする時間帯(初期値 20:00〜05:00) |
| 人工の数え方 | 1日=1人工 / 実働で按分(按分なら所定実働分) |
| 締め日 | 末日 / 20日 / 15日 など |
| 支払期日 | 翌月末 など |
| 請求単位 | 元請けでまとめる / 現場ごとに分ける |
| 経費の扱い | 本体の請求書に含める / 別の請求書にする |

### 現場

表紙の現場名(改行可)と「仕様」欄の文言(規制作業一式 / 作業一式 など)。未登録ならCSVの現場名と「作業一式」。

### 人の単価

元請け(×現場、任意)× 職種 ごとに:日勤単価、夜勤単価、残業の時間単価(人工のみ)。
現場の単価が登録されていればそれを使い、なければ元請けの単価を使う。

### 機材・車両の単価

元請け(×現場、任意)× 品目 ごとの、1日1台(1式)あたりの単価。

## 請求書

### 集計期間と支払期限

- 請求月と元請けの締め日から集計期間を決める(例:2026-10、20日締め → 2026-09-21〜2026-10-20)
- 締め日がその月にない場合(2月30日など)は末日で締める
- 支払期限は「請求月の n か月後の m 日(または末日)」

### 書式(現行のExcel請求書に合わせる)

- **表紙(A4横)**:現場ごとに1行(数量1・単位「式」・単価 = その現場の内訳書の合計)。経費は行を追加。小計・合計、振込先、備考
- **内訳書(A4縦)**:現場 × 職種 ごとに1枚(2枚目以降の職種は「現場名(作業員)」のように付ける)。
  1行 = 日 × 作業内容 × 時間。列は日勤・夜勤(+人工なら残業)+ 使った機材。行が多ければ印刷時に次のページへ続き、見出しが繰り返される

### 内訳の計算

**時間単価の元請け**

- 1人ごとに勤務時間を日勤帯・夜勤帯に分け、延べ時間 × 単価にする
  - 例:夜勤帯 20:00〜05:00 で 19:00〜04:00・休憩60分 → 日勤1時間・夜勤7時間
  - 休憩は長いほうの時間帯から引く
  - 実働分が開始・終了・休憩と合わない場合は警告し、実働分を正とする(差は夜勤側で調整)

**人工の元請け**

- 勤務区分で日勤・夜勤の人工単価を選ぶ。1日=1人工、または 所定内実働 ÷ 所定実働 で按分
- 残業は 残業分 ÷ 60 × 残業時間単価

**機材**

- 台数 × 1日あたりの単価。同じ日・作業内容の行に載せる(なければ機材だけの行を作る)

**共通**

- 金額は整数の円。分単位で計算し、項目ごとに1円未満を四捨五入する

### 消費税(インボイス制度)

- 税率ごとに小計を出し、消費税は請求書1枚につき税率ごとに1回だけ端数処理する
- 表紙の行ごとの「消費税」欄は、行ごとに切り捨てた額を出し、端数の差を金額が最も大きい行に寄せる(欄の合計 = 請求書の消費税)
  - 現行のExcelは行ごとに ×0.1 しているため 0.5円 の端数が出たり、手で直した数字が入ったりしていた。それをなくす
- 端数処理(切り捨て / 四捨五入 / 切り上げ)は自社情報で選ぶ。初期値は切り捨て
- 表紙に登録番号と、税率ごとの対象額・消費税額を記載する

### 請求単位と経費

- 請求単位が「元請けでまとめる」なら1枚、「現場ごと」なら現場ごとに1枚
- 請求書番号:`YYYYMM-元請けID`(現場ごとなら `YYYYMM-元請けID-現場ID`)
- 経費は請求書ごとに手入力で追加する(税率 10% または 対象外)
  - 経費の扱いが「別の請求書」の元請けは、経費だけの請求書 `…-E` を作る

### 出力

- 印刷 / PDF保存(表紙はA4横、内訳書はA4縦。表示中の1件 または すべて)
- 発行日は未指定なら各請求書の締め日
- 請求明細CSV:1行 = 表紙の1行(請求書番号・発行日・元請け・期間・支払期限・現場・仕様・金額・税率・消費税)
- 内訳明細CSV:1行 = 内訳書の1行 × 項目(日勤・夜勤・機材など)

### 警告とエラー

| 段階 | 内容 | 扱い |
|---|---|---|
| 取り込み | 列が足りない / 日付・分の形式が不正 | エラー(その行は取り込まない) |
| 取り込み | 実績IDの重複 | 注意(2件目以降は取り込まない) |
| 取り込み・請求書 | 未確定 / 伝票番号が空 | 注意(請求書には含める) |
| 請求書 | 元請け・人の単価・機材の単価が未登録、元請けIDの重複 | エラー(その実績・機材は請求書に載らない) |
| 請求書 | 実働分が開始・終了・休憩と合わない | 注意(実働分を正とする) |
| 請求書 | 残業があるのに残業単価が0 | 注意 |

## 決定事項

- 書式は現行のExcel請求書(表紙 + 現場ごとの内訳書)に合わせる
- 時間単価は日勤帯・夜勤帯で単価を分ける。夜勤帯は元請けごとに設定(初期値 20:00〜05:00)
- 人工の数え方は元請けごとに選べる(1日=1人工 / 実働で按分)
- 消費税の端数処理は自社情報で選べる。初期値は切り捨て
